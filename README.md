# TypeScript Workshop
Phoenix Programming Club's TypeScript workshop hosted 9/30/2026. Made with NodeJS + Fastify using TypeScript. NodeJS version 20+ recommended.

This is an example project that shows a CRUD backend handling a "Post" resource.

## Build
After downloading the source code, cd into the project root directory and run
```bash
npm install
```

To build and run the project use this command:
```bash
npm run dev
```

The server should now be listening to port 3000. Open a web browser (on the same device) and navigate to `localhost:3000`. You should see something along the lines of `{ message: "Hello world!" }`.
